# Windows 'Message Of The Day' on login.

##Goals
- To have a window pop up on login that displays a message the user has to click away.
- All users receive the same message.
- The message should be defined in a global markdown text file made by the administrator.
-- The text file should only be writable by the 'Administrator' account

##Notes
- It would be preferable to use tools native to a standard window 11 (powershell) installation.
- The development computer runs MacOs, so this probably isn't going to be possible to test locally.
